# Nib — 项目索引

Nib 是 AI 时代的轻量跨平台桌面框架：系统 WebView 壳 + Go 核心。
北极星指标：AI 单次迭代时间 T_iter < 5s。设计全貌见 `design-v0-1`。

当前焦点：M1 已完成——运行时链路、错误路径（`ipc-error-path`）、绑定生成器
（`binding-generator-impl`）、dev harness（`dev-harness-impl`，热替换 ≈1.1s）全部 verified。
M2 诊断（`m2-diagnostics`）进行中：增量 1 结构化事件流已完成并验证
（`event-stream`），支持跨进程转发、重放与 NDJSON 导出。
增量 2 macOS 隐藏窗口驱动已通过独立 review 与实机验证（`driver-e2e`）；
当前推进 CLI `--json` 与 doctor（`cli-structured-output`），随后是 MCP server。
Windows（`webview-windows`）与 Linux（`webview-linux`）绑定仍在 backlog。
正式发布目标与完整功能待办见 `release-v1`：覆盖三平台、完整 IPC、工具链、
安全、安装更新、真实应用验证与框架公开发布。
